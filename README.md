--Project Overview--

The Customer Dashboard is a data visualization project developed using Tableau to transform customer-related data into meaningful and actionable insights. The project focuses on presenting key metrics and customer trends through interactive visualizations, enabling users to explore the data and better understand customer behavior.

This project demonstrates my ability to work with data, develop interactive dashboards, and present information in a clear and structured format. It reflects my interest in using data visualization to support business analysis and data-driven decision-making.

Key Highlights:

-Developed an interactive dashboard using Tableau.

-Presented customer-related metrics and trends visually.

-Designed visualizations to make data easier to explore and interpret.

-Focused on communicating insights to support informed decision-making.
